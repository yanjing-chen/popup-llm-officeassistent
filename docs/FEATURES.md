## 2.1.4 重点修复

- 划词后呼出的六功能按钮条始终位于本插件全部结果窗口之上，避免被上一轮弹框遮挡。
- 呼出按钮时检查实际层叠顺序；已有结果窗口激活时，只将其提到其他结果窗口之前，随后保持按钮条在它们上方。
  不再把结果窗口直接提升为整个父容器的最后一个子 Actor。
- 已经在正确顺序时不反复调整层级。没有额外定时器、全局输入抓取、透明全屏遮罩、截图/克隆或固定 z-position。
- 仅调整本插件控件之间的顺序，不将结果窗强行抬到其他 Shell 系统界面之上。
  锁屏、概览、禁用、按钮超时和 Esc 等原有清理行为不改。
- 这是默认行为，无需新增开关。按钮选定功能后仍另开结果窗口，原有结果保留。

## 保留 2.1.3 的实际模型与显存时间设置

- 六个模型名称不再内置任何示例默认值，也不将旧配置中的名称补进模型列表。
  只显示当前配置后端实际返回的可用模型；DeepSeek 若未安装就不显示，真正安装后仍可正常选择。
- 成功确认列表为空时，六个模型选择框显示 **尚未安装模型**，并禁止选择。
  读取中显示“正在读取模型…”，连接失败显示“无法获取模型列表”，不把连接失败误判为未安装。
- 后端确认旧选择已不存在时清空该选择，显示“请选择模型”；不会擅自改用其他模型。
  仍然存在的独立选择保留。连接暂时失败时只隐藏旧列表，不清除尚未核实的保存值。
- 刷新以及编辑 API 地址/密钥时立即隐藏旧列表，过期请求不能将其他后端的名称重新写回菜单。
- 未选择模型时提示先在设置中选择，不向推理接口发送空模型名，也不回退到示例模型。
- 模型退出显存时间只接受 **0–86400 秒**；0 为回答结束或取消后立即请求卸载，正数为空闲时间。
  默认 **60 秒**，取消“遵循后端”选项；旧 -1 自动迁移为 60 秒，已有非负时间不改。
  图标自动关闭时间的 -1（不自动关闭图标）与模型计时无关，仍保留。

## 保留的选区与按需复制设计

保留 2.1.2 的事件目标获取、窗口内捕获阶段的只读选区处理，以及 GNOME 51 的正文 I 形指针。
以下交互实现本轮不改：

- 在结果窗内处理按下、移动、松开，用原生文字排版命中计算字符位置；不依赖可编辑控件的默认鼠标选择。
- 使用 Pango 字节范围属性显示蓝色背景/白色文字，不依赖可编辑状态、光标可见性或持续键盘焦点。
- 只读状态保留，不会把原回答变成可编辑输入框。中文、重音字母和 emoji 按 Unicode 字符/UTF-8 边界处理。
- 标题复制按钮、邮件底部复制按钮优先复制选中片段；没有选区时保留原来的完整结果复制。
  复制前保留所选内容快照，按钮获得焦点不会导致错误地复制全文。Ctrl+C 同样只复制选区。
- 工具条超时只隐藏图标，不清除选区；选区仍可稍后复制。右击已有选区可以重开六功能工具条。
- 选择六功能后仍保留原结果窗，另开新窗处理所选文本。已实测通过的拖动与多窗口请求代码不改。

测试从鼠标坐标发出完整按下/移动/松开事件，由生产代码创建选区，
不再通过测试直接调用 set_selection() 来构造“选取成功”。

## 已有功能与使用方法

### 绘帧同步拖动（保留 2.1.0 实机通过的实现）

按住 `⠿ LLM …` 标题区域移动窗口。默认使用绑定该窗口 Actor 的 Clutter Timeline，
在绘制新帧前获取最新鼠标位置，不再以固定 16 毫秒作为主更新节奏。
每帧至多应用一次新的位移；不再每一帧额外请求一次扩大范围的 stage 局部重绘，
只在结束时补充最终区域清理。鼠标不动时不反复修改位置、尺寸或样式。

保留 2.0.4 原窗口 translation 平移、拖动时暂缓正文可见更新、松手后补齐、
不透明显示、跨屏边界约束和原有合成标志还原。
原生 Timeline 初始化失败时，才使用原有 16 毫秒非阻塞跟踪作为兼容回退。

没有全局输入抓取、全局鼠标事件过滤器、模态遮罩或嵌套主循环。
窗口关闭/销毁/隐藏、锁屏、概览、显示器变化及禁用扩展时均结束手势并清理回调。
结果窗内的事件处理限定在自身控件树：正文选区事件在窗口内处理，标题/按钮仍走原有路径；不捕获桌面输入。

### 在结果里选词，再调用六功能

1. 在结果正文中用鼠标选中要处理的部分，松手。
2. 在出现的六功能图标中选择“润色”等功能；仅显示设置中已启用的功能。
3. **原结果窗保留，另开一个独立结果窗**，输入文本是刚才选中的片段。
   翻译/解释/润色/自定义仍可先确认风格，再点击执行；邮件/问答沿用原来的输入与发送流程。
4. 新结果也可以继续选词，形成后续结果窗。每个窗口可独立拖动、复制和关闭。

正文为只读可选择文字，不会被直接编辑。支持 `Ctrl+C` 复制选区，
`Ctrl+A` 选择当前文字块。连续问答的每个问/答气泡均可单独选择；
本版不支持一次拖选跨越多个问答气泡。

选区直接从窗口内部的文字控件读取，不依赖跨应用 PRIMARY，不在选词时写入系统剪贴板。
只有按下 Ctrl+C/点击复制按钮时才写入剪贴板；有选区时只复制片段，无选区时复制按钮仍可复制完整结果。
若“弹出模式”为快捷键，先选择文字，再按原快捷键呼出工具条，不自动弹出。

保留选区期间，暂缓该窗口正文的可见更新和自动滚动，后台继续接收完整输出，问答历史和显存计时照常完成。
选择六功能、取消选区或按 Esc 后补齐最新内容；图标自动关闭本身不清除选区。
点击正文空白处可取消选区；若图标已经隐藏，可右击已有选区再次呼出。
标题拖动、正文选择、按钮操作是分开的热区。

### 独立窗口状态

- 每个窗口独立拥有 Soup 请求/取消对象、流式缓冲、问答历史、复制状态、选区和拖动状态。
- 关闭父窗口不关闭已打开的子窗口；关闭一个窗口只取消它自己的请求。
- 点击/拖动结果窗可在结果窗口之间将其置前；功能按钮条可见时保持在全部结果窗之上。
  Esc 先关闭工具条/取消选区，没有选区时再关闭当前活动结果窗。
- 模型发现和显存空闲管理仍共享；同一模型在任意结果窗有活动请求时，不触发插件空闲卸载。
- 修改 API 地址/密钥时取消所有旧请求，保留已有结果；下一次请求使用新配置。
- 本版的模型选择、设置默认值/范围、后端请求与无阴影 CSS 和 2.1.3 保持不变。

## 模型设置与原有功能

### 1. 模型退出显存的时间

位置：界面与交互 → 图标自动关闭时间 → **模型退出显存的时间**。

- `0`：回答结束或取消后立即请求卸载，仅用于具备已确认卸载接口的后端。
- `1–86400`：单位为秒，按该模型在本插件内的空闲时间计时。新请求会取消旧计时，长回答不会中途卸载。

默认值 60 秒。没有“遵循后端”选项；升级时旧 -1 自动改为 60 秒。

卸载只释放加载实例，不删除已下载模型，不清空提示词，也不清除问答历史。
后端可能因为自身更短的空闲策略、资源压力或其他客户端操作提前卸载，本设置不强制让模型至少驻留指定时间。
**共享同一后端模型的其他应用可能受卸载影响。** 插件无法获知所有第三方客户端的使用状态。

| 后端 | 行为 |
| --- | --- |
| Ollama | 从 `/api/tags` 协议确认后，通过空请求 `/api/generate` + `keep_alive: 0` 定时卸载本插件使用过的模型。 |
| LM Studio，提供原生 v1 模型接口的版本 | 请求时传递正数 TTL；空闲后查询实际加载实例并使用 `/api/v1/models/unload`。若同一模型有多个无法区分的实例，则拒绝批量卸载。 |
| 旧版 LM Studio（v0 模型接口） | 正数时间经请求中的 `ttl` 交由后端执行，仅适用于启用 JIT 的自动加载模型。手动加载模型不保证生效，`0` 立即释放不受支持。 |
| Local AI Runtime，提供 1.0 空闲策略接口的版本 | 自动识别 `/v1/runtime/preferences`。设置正数后点击“应用到 Runtime”并确认，服务自行按全局空闲情况安全卸载，通常有最多约 5 秒轮询延迟。此设置持久保存，会影响 SnapMark 等全部客户端。只写 `idle_unload_seconds`，不改预加载/后端/模型配置。 |
| 其他 OpenAI 兼容服务、未提供该接口的旧 Runtime | 模型列表仍可使用；显存设置灰显并明确标注不支持，不向未知地址发送卸载 POST，不强行停止进程。 |

**Runtime 的 `0` 表示禁用自动卸载，并不是立即释放。** 本插件不会把自己的 `0` 误写到 Runtime。
在 Runtime 下请设置正数并确认应用；本插件不会未经确认改写服务的共享策略。
打开设置页、刷新模型列表以及开始普通问答，都不会修改 Runtime 的共享设置。
已经加载但从未在本插件使用过的模型不在 Ollama/LM Studio 插件计时的管理范围内。

### 2. 六个独立的模型下拉菜单

使用您现有的 API 地址和密钥读取同源模型列表；打开设置页自动读取，修改地址/密钥后重新读取，也可点击“自动识别模型”右侧的刷新按钮。
不需要手动输入模型 ID。菜单可以搜索，翻译、解释、润色、邮件、问答、自定义分别保存原有模型配置键。
首次获取成功后，请在需要的功能下选择实际模型。
新安装无示例默认模型；成功返回的列表里没有保存名称时，清除该选择，不显示旧名称，也不自动选择其他模型。
无模型时显示“尚未安装模型”。服务离线或需要登录时显示失败原因并隐藏旧菜单，暂时保留未核实的保存值。
安装或删除模型后点击刷新，菜单重新以实际返回列表为准；不会自动下载模型、安装依赖、启动服务或触发推理。
API 地址支持标准 `/v1/chat/completions`、LM Studio `/api/v0/chat/completions` 及保留前缀的兼容代理路径。
所有探测只发 GET；密钥仅发给配置地址的同源接口，探测不跟随重定向，也不会把密钥或响应正文写进日志。

### 3. 结果弹窗可移动

按住结果弹窗左上方 `⠿ LLM …` 标题区域，拖动到需要的位置，松开鼠标结束。
使用原窗口整体平移，不创建分身；可跨显示器拖动，并限制到目标显示器工作区以内。松手后提交最终位置并更新目标屏幕尺寸约束。
复制/关闭按钮、语言/风格菜单、输入栏和正文区域不作为拖动热区。
拖动中暂缓可见的流式输出和自动滚动，松手后补齐；后续输出改变高度时保留拖动后的坐标，只在触及屏幕边界时作必要约束。
Esc 优先关闭选词工具条或取消选区；没有选区时关闭当前活动结果窗，不关闭其他结果窗。
本次没有增加重启位置记忆或改变划词图标的鼠标附近弹出逻辑。
